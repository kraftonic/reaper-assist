# Studio (`src/studio`)

The Studio tab: quick starts that don't need a chat.

| File | What it does |
|---|---|
| `genres.ts` | 10 genre beat templates (tempo, key, sections, instruments, drum patterns). Renderer-safe. |
| `templates/build.ts` | Turns a genre into one batch of REAPER commands (one undo step). |
| `catalog.ts` | Curated free plug-ins and sample sources by genre, each with its licence terms. Renderer-safe. |
| `plugins.ts` | Which plug-ins are installed. |

Catalog entries must link to the official download page and state the licence honestly. Only list things that are free to use in released music.
